# Meet's Virtual Infusion Pump

A single-page practice simulator for learning how to program an infusion pump (modelled on the B. Braun Infusomat Space workflow used in RRC Polytech's nursing lab): loading the line, priming, programming a primary IV fluid, and adding a secondary.

Open the live page: https://manmeet2323.github.io/meets-virtual-infusion-pump/

**Unofficial practice tool.** Not affiliated with or endorsed by B. Braun. Drug names, concentrations and limits are illustrative only and are not clinical reference. Always follow your facility's policy and the manufacturer's Instructions for Use.
